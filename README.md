## Steps to prepare application

1. Install nodejs v22.13.0+
2. Install yarn v1.22.22
3. Open project root folder
4. Add .env file according .env.example
5. Run yarn

## Run application

1. Run yarn start

## Run tests

1. Run yarn test

## Use openapi documentation

1. Open root endpoint
2. Enter in expore field http://localhost:3000/static/openapi.yaml
